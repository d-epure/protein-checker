Welcome to ProteinComplete

This app needs your Anthropic API key to analyze your meals. It's saved only in your browser — never sent anywhere except directly to Anthropic.

Where to find your key:
1. Go to console.anthropic.com
2. Click API Keys in the left sidebar
3. Copy your existing key or create a new one
4. Paste it below
Please enter a valid Anthropic API key (starts with sk-ant-)
